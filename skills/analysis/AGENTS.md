# skills/analysis

## Purpose

台股分析、財務模型、技術分析。**純分析型**：讀資料、算指標、給判斷，
但不直接執行外部動作（不下單、不發訊息、不寫入生產資料庫）。

## For AI Agents

### 這個資料夾工作時要注意

- 已驗證正確的計算公式（技術指標、估值模型等）遷移時原封不動搬進 `scripts/`，
  不要重寫演算法本身（見根目錄 AGENTS.md 第 0 節第 4 條）。
- 如果一個技能除了分析還會「順便」呼叫外部工具產生副作用，它的定位跑掉了，
  要嘛拆成純分析 + 另一個 `skills/agents/` 底下的執行技能，要嘛整個搬去 `agents/`。

### 常見錯誤

- 誤把應該放 `skills/agents/` 的執行型技能留在這裡，因為分析和執行看起來都是
  「進去看資料」。判斷標準只有一個：這個技能**會不會**對外部世界產生實際副作用。
